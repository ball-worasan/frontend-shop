# SHOP-004 — หน้าแรกของร้าน

หน้าแรกเรียง Hero → เลือกเกม → สินค้าแนะนำพร้อมแท็บทั้งหมด/ไอดี/ไอเท็ม → สินค้าล่าสุด → วิธีซื้อ → Footer ตาม SHOP-001 ภาพ Hero เป็น SVG ที่สร้างในโปรเจกต์และไม่มีภาพหรือสิทธิ์ของเกมจริง

การ์ดเกมเปิด `/products?game=...` การ์ดสินค้าเปิด `/products?q=...` เพื่อให้ไปถึงสินค้าจำลองที่มีอยู่จริง ก่อนมีหน้ารายละเอียดสินค้าใน SHOP-006 ปุ่มซื้อหลักเปิด `/products`; ขั้นตอนซื้อและชำระเงินยังไม่เปิด

หน้าใช้ข้อมูลจำลองจาก `lib/products.ts` และภาพ placeholder เดิม พร้อมข้อความระบุสถานะตัวอย่าง ชื่อสินค้าและราคาแสดงในกริดสองคอลัมน์บนมือถือ

## ผลตรวจ

- `bun run lint`, `bunx tsc --noEmit` และ `bun run build` ผ่าน
- Production server ตอบ 200 สำหรับ `/`, ภาพ Hero, ลิงก์เกม และลิงก์สินค้าตัวอย่าง
- ตรวจภาพหน้า desktop 1440px และมือถือ 504px แล้ว; บนมือถือการ์ดสินค้าเรียงสองคอลัมน์และข้อความไม่ล้น
- ยังไม่ได้จำลอง viewport 390px หรือทดสอบการเปลี่ยนแท็บด้วยเครื่องมือโต้ตอบใน browser

## daisyUI

อ่าน skill ที่ `.agents/skills/daisyui` และใช้ชื่อคลาสของ Hero, Card, Badge, Button และ Tab ในหน้าใหม่ อย่างไรก็ตาม package `daisyui` ยังไม่ได้ติดตั้ง เพราะ package registry ถูกปฏิเสธในสภาพแวดล้อมนี้ จึงมี Tailwind/CSS รองรับภาพที่ render อยู่ เมื่อ registry ใช้งานได้ ให้ติดตั้ง daisyUI 5 และเพิ่ม `@plugin "daisyui";` ใน `app/globals.css` แล้วตรวจธีมและแท็บอีกครั้งก่อนปิดงาน
